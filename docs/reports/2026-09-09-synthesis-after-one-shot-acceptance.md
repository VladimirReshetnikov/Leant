The original priorities 1–4 and the full rank-N/impredicative synthesis objective

## What changed

The [one-shot contextual milestone](2026-09-09-one-shot-contextual-output.md)
passes **2,371 tests in 16 complete suites** under strict builds, **64 public
queries** with **5,354 displayed alternatives** compiled and evaluated at their
original signatures, and **350 Church signatures per Haskell engine**. The
Exference extended behavior regression passes **13 operations**, one False
query and **28 independent oracle controls**. Displayed alternatives are not a
count of unique implementations.

The accepted changes cover lexical context alongside specialization certificates,
local scope for internal flexible types, and the documented one-shot matrix in
both Haskell engines. The type-only all-selection oracle now permits valid
closed instance choices; controlled tests separately pin the exact selections.
These items no longer justify keeping certificate implementation at the front
of the queue. Exact public-output replay remains mandatory for later changes.

Leant still uses Djex `bfc3692e`. Its separate deadline repair has **nine completed
integration gates**, including **705 unit tests**, but the final Exference
signature corpus lacks terminal acceptance. Two attempts have explicit
interruption records with an unknown termination cause. These are unfinished
validation, not accepted runs or evidence of a particular backend defect.
The Haskell milestone does not validate that repair or promote the native
dependency.

The best next investment is a recoverable, terminally accepted native milestone,
followed by small user-visible syntax and behavior increments. Optimization work
should enter the queue when measurements identify the cost it will remove.

## Unchanged scope

The behavior objective remains **(13 extended + 19 supplied-default operations)
× (2 Haskell engines + 3 Lean modes) = 160 cells**. This is the target size, not
the accepted count; negative controls and exact replays are additional. Partial
Lean cases continue to use the agreed supplied default or inhabitance assumption.
Behavioral queries retain the approved named-function-plus-`where` syntax.

Previously accepted elaboration, ordinary structures, canonical Haskell
Exference tree synthesis, native List recursors and contextual fragments remain
regressions at their recorded revisions. Native tree synthesis is unaccepted in
all three modes. No aggregate pass percentage is inferred across differing
revisions or settings, and this re-triage does not declare complete support.
